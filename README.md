# ガラクタ姫の異食レストラン（試作 0.3）

ガラクタだらけの異世界で、ロボットがロボットを相手に経営する異食のレストラン。自動化×経営ゲームの構造確認用プロトタイプです。グラフィックはすべて仮のものです。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- 下の棚から設備を選び、空きマスをタップすると配置できます。ドラッグすると、ドラッグした方向に向けて連続で配置します。
- 「見る・回す」モードで設備をタップすると、中身を確認でき、向きのある設備なら回転します。同じ設備を選んでタップしても回転し、違う設備でタップすると入れ替わります。
- 向きは右下の矢印ボタン、`R` キー、右クリック、マウスホイールで回せます。
- 「回収」は設備をインベントリに戻します。「リセット」はマスの上のオブジェクトを消します。メニューからは盤面のオブジェクトをすべてリセットできます。
- 盤面の左にいるガラクタ姫をタップするとショップが開き、ローズ・トニックで設備を売り買いできます。
- 進行はブラウザに自動保存されます。
- **テストモード**（`src/defs.js` の `testMode: true`）の間は、ローズ・トニック999で始まり、メニューに「テスト用：ローズ・トニック +999」ボタンが出ます。以前の保存データが残っている場合は、このボタンを使うか「最初からやり直す」を押してください。製品版では `testMode: false` にします。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/defs.js` | データ定義。設備・オブジェクト・加工レシピ・価格・各種数値 |
| `src/sim.js` | シミュレーション本体（DOM に依存しない） |
| `src/render.js` | 仮グラフィックの描画。見た目の差し替えはここだけで完結させる |
| `src/main.js` | 入力、UI、ゲームループ、保存 |

新しい設備・オブジェクト・加工工程は、ほとんどの場合 `defs.js` に足すだけで増やせます（見た目は `render.js` に追加）。

## 設備カテゴリ

| カテゴリ | 働き | 設備 |
|---|---|---|
| 生成所 | 向いている方向の隣マスが空いていれば、オブジェクトを生成する | ゴミコンテナ |
| 運搬経路 | 乗ったオブジェクトを向いている方向へ流す | バケツコンベア、タイヤコンベア、仕分けコンベア・タイヤ |
| 加工所 | 中のオブジェクトを加工して、向いている方向へ出す。加工後の状態が無ければゴミになる | 練り機 |
| 置き場 | 乗ったものには何もしない | レジャーシート |
| 廃棄所 | 乗ったオブジェクトを消す | シュレッダー |
| インテリア | オブジェクトは乗らない。置いてあるだけで効果がある。同じインテリアは5つまで | 客寄せ看板 |

### タイヤコンベア（分配・合流）

- 各タイヤコンベアは、置いたときの向き（本来の出口）を持ちます。
- **分配：** 隣にあるタイヤコンベアが「自分から離れる向き」に置かれていたら、そこも出口になります。たとえば右向きの列の途中に上向きのタイヤコンベアを隣接させると、T字の分岐になります。出口は順番に回して使い、詰まっている出口は飛ばします。来た方向には戻しません。
- **合流：** このマスへ向けてオブジェクトを出す隣接設備（コンベア・生成所・加工所）はすべて入口になります。入口は順番に回して、均等に受け入れます。
- 平行に並べた2本の列は、互いに向きが合わないので干渉しません。
- **エラー：** 4方向すべてが入口、またはすべてが出口になると、赤い「!」が出てそのマスが止まります（受け取りも送り出しもしない）。周りの向きを直せば自動的に復帰します。
- ドラッグ配置では、列の端からドラッグしたときだけ端の向きを付け替えます。列の途中からドラッグすると、元の列の向きは変えずに分岐を引けます。

### 仕分けコンベア・タイヤ

- 本流の向き（白い矢印）と、仕分け先（黄色い矢印）、比較マス（点線と「目」の側）を持ちます。比較マスと仕分け先は本流をはさんで反対側です。
- オブジェクトが乗った時点で比較マスにあるオブジェクトを見て、同じ種類なら仕分け先へ、違えば本流の先へ流します。比較マスが空なら本流の先です。比較マスに何の設備があるか（無いか）は関係ありません。
- 行き先は乗った時点で決まり、出口が詰まっていればそのまま待ちます。
- 回転は「同じ向きで左右反転」を挟んで8回で一周します。
- どの方向から入ってきても受け取ります。

### 客寄せ看板

- ゲーム開始時に中央に1つ置かれています（回収・売却も可能）。
- ロボットたちは看板の周りに集まり、画面外のうち看板に近い側から出てきます。看板が複数あるときは、1体ごとにどれか1つを選びます。
- 来店ペースと同時に画面にいる上限は、看板の数だけ倍になります。看板が0枚のときは1枚と同じペースで来て、盤面のランダムな位置で立ち止まります。

## 仕様の解釈（仕様書に明記がなく、仮で決めたもの）

- **1マスに乗れるオブジェクトは1つまで。** 移動先のマスが空いていなければ待ちます。
- **何も置かれていない地面にもオブジェクトは乗ります。** 地面に乗ったオブジェクトは動きません。
- 生成所と看板のマスにはオブジェクトが入れません。それ以外の設備は、どの方向からでも受け取ります。
- 加工所は受け取った向きに関係なく、自分が向いている方向へ出力します。出力先が詰まっていれば、加工後の状態のまま待ちます。
- バケツコンベアに複数の方向から入力されると、先に空いた側から入ります（公平な合流は「合流機能」を持つ上位の設備に任せる想定）。
- 見た目について：バケツコンベアは横から1本だけ入力があると曲がり角の形になり、それ以外の追加入力は短い継ぎ目として描きます。
- 客ロボットは立ち止まった位置から一番近い、料理の乗ったシートへ向かいます。取り合いになったときは、そのシートにより近い客が勝ちます（距離の短い組み合わせから順に決めます）。負けた客は残りのシートのうち一番近いものへ向かいます。料理は向かう途中で他の客に取られないよう予約されます。料理が無いまま一定時間たつと帰ります（「空腹で帰った」として数えます）。
- 客寄せ看板の購入は、所持数（設置済み＋在庫）が設置上限の5に達すると止まります。
- 客寄せ看板の価格は20です。
- タイヤコンベアの価格は5、仕分けコンベア・タイヤの価格は12です。
- シュレッダーは、オブジェクトが入ってくる途中から処理を始めます。こうしないと、移動時間と処理時間が足し算になってバケツコンベアの流れにも追いつかないためです（今はバケツなら余裕あり、タイヤだと少しだけ追いつかない速さ）。
- 最初の所持品：ゴミコンテナ×1、バケツコンベア×6、練り機×1、レジャーシート×1、シュレッダー×1、トニック0。
- 売値は買値の半分（切り捨て）。売れるのはインベントリにある設備だけです。
- ゴミダンゴ（コモン）は 1 トニック。
